# Pine

A security-focused desktop browser built on Firefox, with an Arc-style sidebar
and multitasking: Spaces, Favorites, auto-archiving tabs, split view, a
command bar, Peek and a mini window for links from other apps.

Pine is a thin layer on upstream Firefox Release: build configuration, default
prefs, Pine's own UI code and a small, documented set of patches. Keeping the
diff small lets us ship each Firefox security release within hours.

**Status:** design phase. Start with the [design document](docs/design.md).
